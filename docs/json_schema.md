# GitPulseMLC JSON Output Specification

This document describes the structure of the JSON output generated by `gitpulse --json`.
You can also find the formal JSON Schema in [schema.json](./schema.json).

## Root Object

| Field | Type | Description |
| :--- | :--- | :--- |
| `version` | string | The version of GitPulseMLC that generated the report. |
| `summary` | object | Global statistics across all scanned repositories. |
| `results` | array | List of `RepoStatus` objects, one for each project. |

---

## Summary Object

| Field | Type | Description |
| :--- | :--- | :--- |
| `total` | int | Total number of projects scanned. |
| `dirty` | int | Number of repositories with uncommitted changes, in the repository or in a submodule. |
| `ahead` | int | Number of repositories with local commits not yet pushed. |
| `behind` | int | Number of repositories with remote commits not yet pulled. |
| `errors` | int | Number of projects that failed to scan (e.g., directory missing). |
| `public` | int | Number of own repositories with at least one publicly readable remote. |
| `third_party` | int | Number of third-party repositories. They are not counted in `dirty`, `ahead`, `behind`, `public` or `submodule_pointers`. |
| `third_party_updates` | int | Number of third-party repositories behind their upstream. |
| `submodule_pointers` | int | Number of repositories with a submodule that moved past the commit the parent records, and nothing else to do in it. |

---

## RepoStatus Object

| Field | Type | Description |
| :--- | :--- | :--- |
| `name` | string | The display name of the project. |
| `third_party` | boolean | `true` if the project is listed in `[third_party]`: somebody else's repository, checked out to look at or test. Its remotes are not checked for visibility. |
| `path` | string | The absolute filesystem path (or shortened path if replacement settings are used). |
| `current_branch` | string | Name of the currently checked-out branch. |
| `last_commit_id` | string | SHA-1 hash of the latest commit on HEAD. |
| `last_commit_msg`| string | Subject line of the latest commit. |
| `last_commit_at` | string | ISO 8601 timestamp of the latest commit. |
| `is_clean` | boolean | `true` if there are no uncommitted changes. |
| `modified_count` | int | Total count of modified files. |
| `stash_count` | int | Number of entries in the git stash. |
| `changed_files` | object | Map of file extensions to counts (e.g., `".go": 3`). |
| `ahead` | int | Commits ahead of the tracking remote branch. |
| `behind` | int | Commits behind the tracking remote branch. |
| `has_no_remote` | boolean | `true` if the repository has no configured remotes. |
| `remote_url` | string | Fetch URL of the first remote (`origin` if present), without credentials. |
| `remotes` | array | List of `RemoteInfo` objects, `origin` first; omitted when there is none. |
| `visibility` | string | Visibility of the most open remote: `public`, `unknown`, `private`, `local`, or `none` without remotes. |
| `local_branches` | array | List of `BranchInfo` objects for all local branches. |
| `submodules` | array | List of `SubmoduleInfo` objects; omitted when the repository has none. |
| `error` | string | Error message if the scan failed (only present on error). |

---

## BranchInfo Object

| Field | Type | Description |
| :--- | :--- | :--- |
| `name` | string | Name of the local branch. |
| `is_head` | boolean | `true` if this is the active branch. |
| `ahead` | int | Commits ahead of remote. |
| `behind` | int | Commits behind remote. |
| `last_commit_at` | string | ISO 8601 timestamp of the last commit on this branch. |
| `is_stale` | boolean | `true` if the branch is older than 30 days (excluding main/master). |

---

## RemoteInfo Object

| Field | Type | Description |
| :--- | :--- | :--- |
| `name` | string | Remote name, e.g. `origin`. |
| `url` | string | Fetch URL; HTTP(S) URLs lose user and token, other URLs their password. |
| `host` | string | Real host name with SSH aliases resolved; absent for file remotes. |
| `visibility` | string | `public` (readable without credentials), `private` (external, anonymous read refused), `local` (file path or local network, never checked online) or `unknown` (offline without cached result, or host unreachable). |

---

## SubmoduleInfo Object

A submodule is recorded in its parent as one commit hash. A submodule path whose only change is a newer checked-out commit does not make the parent dirty; it is reported here instead.

| Field | Type | Description |
| :--- | :--- | :--- |
| `path` | string | Path of the submodule, relative to the parent's worktree. |
| `recorded_commit` | string | Commit the parent's index records. |
| `current_commit` | string | HEAD of the checked-out submodule (absent if not initialized). |
| `pointer_ahead` | int | Commits the submodule's HEAD is past the recorded commit. |
| `pointer_behind` | int | Commits the recorded commit is past the submodule's HEAD (run `git submodule update`). |
| `pointer_staged` | boolean | `true` if a new pointer is staged in the parent; it then also counts in the parent's `changed_files` as `(submodule)`. |
| `not_initialized` | boolean | `true` if the submodule is declared but not checked out. |
| `status` | object | The submodule's own `RepoStatus` (dirty state, branches, stashes, nested submodules). |

---

## Example Output

```json
{
  "version": "1.1.0",
  "summary": {
    "total": 1,
    "dirty": 1,
    "ahead": 0,
    "behind": 0,
    "errors": 0
  },
  "results": [
    {
      "name": "my-project",
      "path": "@/dev/my-project",
      "current_branch": "feature/ui",
      "is_clean": false,
      "changed_files": {
        ".go": 2,
        ".md": 1
      },
      "local_branches": [
        {
          "name": "main",
          "is_head": false,
          "ahead": 0,
          "behind": 0,
          "is_stale": false
        }
      ]
    }
  ]
}
```
